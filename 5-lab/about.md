# Описание
Небольшой учебный проект на Python, демонстрирующий работу с классами, методами и стандартными модулями. В коде реализованы три независимых класса: `Circle`, `Person` и `Calculator`.

## Структура проекта
- **Circle** — работа с геометрией круга  
  - вычисление площади  
  - вычисление периметра  

- **Person** — работа с персональными данными  
  - хранение имени и национальности  
  - вычисление возраста по дате рождения  

- **Calculator** — базовые арифметические операции  
  - сложение  
  - вычитание  
  - умножение  
  - деление

## Используемые модули
- `math` — для математических вычислений  
- `datetime` — для работы с датами и расчёта возраста
